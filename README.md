# Soulful Cellar Website

## Description
The Soulful Cellar Website is a static web application designed to promote the Soulful Cellar venue. It provides users with access to audio promotions and information about upcoming events.

## Features
- Audio content for promotional purposes  
- Information on upcoming events  
- Simple and responsive user interface  

## Installation
No installation is required.

## Usage
To view the website:

1. Upload all project files to a web server and navigate to the root directory, **or**  
2. Open the `index.html` file in a web browser  

## Configuration
No configuration is required.

## Technologies
- HTML  
- CSS  
- JavaScript
